# Prototype problem 

To develop the DQC lets use the following toy problem: We have an experiment
that generates linear data, picture an experiment or Ohmmic resistors or Hookean
springs. At each run the apparatus will swipe the controlled variable (like
voltage, or position) to N positions and measure the dependent variable (Current
or force), it does so and generates a CSV with the positions. Imagine we are
doing so for many unknown materials to classify them and we have a lab doing this
work.

Now we want to build a pipeline that with each run of this apparatus, fits a
linear model, what we want to get and track the value, then another stage takes
the fitted model, calculates the residuals and test them for normality.

## Inputs/Outputs and related visions

### Apparatus (Initial input)


Output:
  Therefore first we will get as an input the apparatus exit. A CSV with the
  following scheme:

  - x: float - dependent variable 
  - y: float - independent variable

View:
  Plot last Acquisition

### Stage One

For the second stage we get the path of a file generated by the apparatus as
input and as output we want the linear and angular coefficients.

Output:
  So we write a JSON with the coefficients.

View:
  Historical view of a line plot with two curves, one for each coefficient. 

### Stage Two

At stage two we load the linear coefficients calculate the residuals and run a
statistical test for normality.

Output:
  Write json with the result of the normality test 0 or 1. 

View:
  Line plot
